# QC Video

Ứng dụng xem video kiểu YouTube.

## Tính năng
- Feed video
- Tìm kiếm
- Lọc theo danh mục (Nature, Tech, Music, Travel)
- Trình phát video (AVPlayer)
- Giao diện tối

Video mẫu dùng nguồn công khai (Google sample videos).

## Build IPA
Vào **Actions** → **Build QC Modules IPA** → **Run workflow**

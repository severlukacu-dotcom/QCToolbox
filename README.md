# QC Video

Ứng dụng xem video kiểu YouTube (phiên bản local).

## Tính năng
- Feed video + tìm kiếm + lọc danh mục
- **Đăng ký / Đăng nhập** (lưu trên máy)
- **Tải video lên** (chọn file từ Files)
- Tab **Của tôi** xem video đã tải
- Trình phát video

### Lưu ý
Tài khoản và video chỉ lưu trên thiết bị này. Muốn chia sẻ giữa nhiều máy cần backend (Firebase, server riêng…).

## Build IPA
Vào **Actions** → **Build QC Modules IPA** → **Run workflow**
